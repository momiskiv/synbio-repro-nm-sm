# Introduction to Synthetic Biology and Bioinformatics Practical Exercises

**Authors:** Scarlett Manley and Naomi Musto  
**Institution:** Cranfield University  
**Programme:** EngBio4Env — Module 1

Code, designs and supporting material for the module's practical exercises.

| Directory | Contents |
|---|---|
| exercise_02_dna_assembly/ | Benchling and OpenCloning sequence designs, primers and assembly workflows. |
| exercise_04_immigration_extinction/ | Separate Naomi and Scarlett implementations of the immigration–extinction exercise. |
| exercise_05_polymer_clustering/ | Installable polymer-clustering simulation package, example configurations, model documentation and tests. |

## Using Exercise 5

The package generates figures and data from configurable simulations.
Users can download its folder independently, install its dependencies,
and choose or edit the supplied example configurations.

See the [Exercise 5 installation and usage instructions](exercise_05_polymer_clustering/README.md#install-and-run-on-linux).
Generated simulation results are excluded from version control.
